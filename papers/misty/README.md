# Misty: UI Prototyping Through Interactive Conceptual Blending

Yuwen Lu, Alan Leung, Amanda Swearngin, Jeffrey Nichols and Titus Barik. CHI 2025. [doi:10.1145/3706598.3713924](https://doi.org/10.1145/3706598.3713924)

## What is here

- `paper/`: the paper split into 13 Markdown files and 3 figure images, made from the arXiv HTML version, which arXiv renders from the authors' LaTeX source. Each top-level section is one Markdown file; math is written as LaTeX and tables as Markdown tables. Figures are the original image files.

Give `paper/` to the coding agent. This README stays outside it so the agent sees only the paper.

## Changes from the original

- Reformatted into one Markdown file per section.
- Running headers, footers and page numbers removed.
- No figures or tables were moved between sections.
- Nothing was reworded or shortened. Footnotes are marked [Footnote: ...] and the authors' figure descriptions are labelled as such.

## Known issues

- Figures 2 and 3 (user study charts) are drawn in LaTeX and have no image file in the HTML; they are cropped from the PDF.
- The authors' figure descriptions contain an unexpanded macro, \sys{}, which stands for Misty.
