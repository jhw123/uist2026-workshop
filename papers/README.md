# Papers

Each folder holds one paper, converted for coding agents: `paper/` has one
Markdown file per section and the figures. The paper's `README.md` gives the
citation, the source, the license and every change made in converting it.

The text and figures belong to the papers' authors and are shared here for
the workshop under the licenses below.

its PDF, because it is not on arXiv. The arXiv versions are preprints and can
differ slightly from the published versions.
