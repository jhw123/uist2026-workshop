# Revibe prompts

The prompts from Adar et al., "Revibing Code from Papers" (Sections 4.2 to
4.4) that the workshop uses, copied word for word. The hackathon page has the
same prompts to copy, with your paper filled in; you send them to the agent one
step at a time. The paper's rubric prompt is not here: the workshop prepared a
rubric for each paper, and you grade on the hackathon page.

| File | Step | Who uses it |
|---|---|---|
| 2_build.md | 1, build the system from the paper | the agent |
| 3_debug.md | 2, fix errors until it launches (repeated) | the group sends errors; the agent fixes |
| 4_complete.md | 3, add missing features; the result is version 1 | the agent |
| 5_aided.md | 5, fix what the graded rubric reports (and any further round) | the agent, with the grades from the hackathon page pasted in |
