Built by Claude Code (Claude Opus 5.5) from the paper.
All three editing stages work end to end: ten AI rough cuts, B-roll and text-effect alternatives, compared in timeline and transcript views (edited or source-aligned), organised by sorting, pinning and archiving, and customised by edit, generate-new, Surprise me and recombine prompts. The group graded all 15 rubric tests full.

## Built

- Versions outline; ten rough cuts per upload, each with its own player that plays only its selected parts.
- Sections extracted from the source and shared by all versions (same name and colour); visually concrete keywords.
- Timeline view: section bar with labels and a filmstrip; hover for thumbnails, click to play; Extracted / Original Timeline toggle with lighter excluded parts and their thumbnails and topic keywords.
- Transcript view: side-by-side versions, section headings (click to play, collapse), mini timeline, bold visual keywords, full source transcript with excluded text greyed, synchronised scrolling.
- Sorting per stage (duration, sections; number of effects, media type, style); pin to top, archive to bottom.
- EDIT prompt (result below the original as "#N-Edited" with a change summary), GENERATE NEW, Surprise me, recombination by version ID (new results pinned).
- B-roll stage (thumbnails with keywords above the bar, hover shows the covered scene, overlays in the player, highlighted sentences, "Content" strip) and text effects stage (quoted keywords, narration on hover, title / subtitle / lower-third styles).
- Upload of your own video with a transcript; projects saved automatically.

## Instructions from the group

- Use three action buttons per variation (add next stage, pin, archive) instead of four, matching the original: the separate re-generate (pencil) button was removed, since the EDIT button next to each title already does it.
- Fix scrolling that made views hard to read (B-roll and text effects timelines did not scroll with their rows).

## Assumptions

- Transcript segments are the smallest unit of a cut (no word-level trimming).
- The ten generations per stage use the 3x3 combinations of the Appendix B attributes (plus one repeat), one LLM call each.
- A B-roll covers its sentence for 2-6 seconds; a text effect shows from its phrase for 2.5-5 seconds.
- Recombining B-roll can copy an exact image from a named version (`from: #N`).
- The text stage shows the inherited B-roll as small insets on the filmstrip.

## Substitutions

- GPT-4o -> Claude Haiku through the workshop LLM bridge (JSON output; no API key).
- Whisper API -> the provided transcripts; uploads need a Whisper JSON or SRT file.
- Stock media API -> keyword search of the provided B-roll library (39 items); the LLM is shown the library's keywords. Uploaded videos show a "No stock match" card when nothing fits.
- Remotion -> a custom browser player that plays the edit list and overlays B-roll and text.
- React + d3 -> plain JavaScript modules; thumbnails extracted in the browser.
- An offline stub (heuristics, labelled in the top bar) when the bridge is not running.
