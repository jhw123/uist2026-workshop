Built by Codex (GPT-6) from the paper.

Initial build of the paper’s static mobile UI conceptual-blending workflow. The canvas, image/region inputs, global and localized blending, semantic refinement, code editing, regeneration and repair are implemented. Real bridge calls were exercised; model output still benefits from inspection and manual corrections.

## Built

- Infinite canvas with example and source nodes, pan/zoom, branching outputs and lineage connections.
- Screenshot/sketch upload, rectangular crop, actual target highlighting and drag/drop, plus coordinate and target-list alternatives.
- Color, Layout, Content and Customize options; context-aware model prompts preserve source content and address repeated elements.
- Semantic change toggles and generated color/range/text/select widgets; regeneration, render repair and a collapsible live code editor.
- Browser autosave, portable workspace import/export, source export, undo/redo and setup/developer guides.

## Assumptions

- Rebuilt the paper’s implemented single-screen static UI scope. Discussion proposals for interactive multi-screen/animation blending remain future work.
- Example nodes require images only. Source input is a self-contained React/Tailwind component or HTML document.

## Substitutions

- GPT-4o → the workshop’s signed-in Codex bridge (gpt-6-luna during testing); no API key needed.
- React Flow → native pointer/SVG canvas; React Live → local Babel/React sandbox; Tailwind browser runtime and inline SVG icons.
- Original illustrative screenshot, sketch and stock SVGs provide sample material; the paper’s composite figure was inspected for interaction design.
- Fine widget values use an explicit Apply action to avoid repeated requests while dragging.

## Still missing

- No intentionally omitted feature from the paper’s implemented static-screen workflow. AI results are imperfect: a tested local layout request also altered colors, and one color adjustment left weak foreground contrast. Semantic controls/manual editing allow repair; exact constraint compliance is not guaranteed.
- Arbitrary external package imports, React Native project execution and custom design-system mapping are not supported automatically.
