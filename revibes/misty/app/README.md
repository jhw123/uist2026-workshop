# Misty (revibe)

A rebuild of **Misty: UI prototyping through interactive conceptual blending** (Lu et al.), made from the paper alone for the Revibing HCI workshop at UIST 2026. You blend example images (screenshots or hand-drawn sketches) into work-in-progress React + Tailwind UI code on an infinite canvas.

## Launch

You need Node.js 18 or later, Python 3, and Claude Code installed and signed in (`claude`).

1. **Start the LLM bridge** in its own terminal, from the repository root (`uist2026-workshop/`):

       python3 llm-bridge/bridge.py claude

   Check it at http://localhost:8787/health. Misty's model calls go through it, so no API key is needed.

2. **Start Misty** in a second terminal:

       cd revibes/misty/app
       npm install        # first time only
       npm run dev

   Open http://localhost:5180. The top bar shows a green "Model: claude · haiku via LLM bridge" label when the bridge is reachable.

If port 8787 is taken, start the bridge on another port (`python3 llm-bridge/bridge.py claude 8788`) and start Misty with `MISTY_BRIDGE_URL=http://localhost:8788 npm run dev`. If port 5180 is taken, Vite picks the next free port and prints it.

## Use

The canvas starts with a reference example (a store page) and a source UI (the "Find parks" cards from Figure 1 of the paper). Pan by dragging the background, zoom with the scroll wheel or the controls at the bottom left, and move nodes by dragging their title.

**Add material**
- *Add example* uploads screenshots or sketches. You can also drop image files onto the canvas or paste an image. Each becomes a **Reference Example** node.
- *Sample examples* adds example images drawn for this rebuild, including a hand-drawn sketch.
- *Add source UI* adds a sample UI (parks, profile, reading list) or your own pasted React + Tailwind code. Each becomes a **Code Render** node.

**Global blending (node connection)**
Drag from the handle on the right edge of a Reference Example to the handle on the left edge of a Code Render. Misty blends the example's visual style and layout into your UI's content and creates a new Code Render to the right, linked by an edge.

**Localized blending (drag-and-drop)**
1. Draw a rectangle on a Reference Example to select a section. *Undo* clears it and *Done* confirms it.
2. Drag the dashed section onto part of a Code Render. While you hover, the section it would blend into pulses, and similar elements (for example, the other cards in a list) get a dashed outline. *Drag the whole screen* drags the entire example instead.
3. Drop it, then pick one or more aspects in **Pick Blending Option**: *Color*, *Layout*, *Content* (add the selected UI elements) or *Customize* (type your own aspect). Press *Next*.

**Semantic diff (Applied Changes)**
Every blending output lists its changes by category (layout, color, font, and so on), each with an on/off toggle. Turning a category off removes that kind of change and turning it on brings it back. Misty asks the model to update the code, which takes a few seconds. Open a category with its arrow to see single class changes: toggle one, or edit its Tailwind class and press Enter for fine control. These apply instantly when the class can be swapped directly. *Reset All* returns to the output as generated. The arrow on the left of the panel collapses it.

**Refine**
- *Show Code* opens the live code editor on the right. Edits render as you type. The tab on the right edge expands or collapses the editor, and *Copy* copies the code.
- *Fix Render* repairs broken code. It first applies regular-expression rules (imports, `class` attributes, unknown icons, image paths). If those change nothing, it asks the model, passing along the render error when there is one. It pulses red when the code fails to render.
- *Regenerate* runs the node's blending operation again.
- Blend into any node, original or output, to branch and compare alternatives side by side. Delete a node with its × or the Delete key.

The canvas is saved in your browser (IndexedDB) and survives a reload. The bin icon at the top right clears it.

## Differences from the paper

- **Model**: the paper used OpenAI GPT-4o. Here the workshop LLM bridge answers with Claude Haiku through Claude Code.
- **Stock photos**: the prompts refer to stock photos in `/stock/`, which the paper does not include. This rebuild uses scenic images generated by `scripts/make_stock.py`.
- **Example images**: the samples are drawings made for this rebuild, not the authors' examples. Upload your own screenshots for realistic blends.
