Built by Claude Code (Claude Opus 5.5) from the paper.
Version 2 fixes the two partial tests from the v1 grades: erasing part of the
sketch now reliably leaves those slots unconstrained, and infilling between a
written beginning and ending keeps both. The group's grades had no notes, so
the causes below are the agent's best guess. The infill was checked through
the API; the browser interface was not tested by the agent.

## Changed
- **T-06, eraser:** the eraser now removes any part of the green band it
  touches, not only the band's centre line. Ends left by erasing no longer
  "snap" onto the neighbouring sentence slot, so an erased slot really has no
  target. Erased slots show a dashed "no target" marker on the canvas, the
  sentences generated there are drawn as hollow dots, and the status line
  counts them.
- **T-09, infilling:** a stroke drawn across a written beginning and ending
  used to regenerate those two sentences too, which destroyed the ending. Now
  the writer's own sentences (typed or edited) are never overwritten by a
  stroke or by Generate Again; only blanks and generated sentences are.
- **T-09, infilling:** each infill request now tells the model how many
  sentences are still missing before the ending, and the last missing sentence
  must connect both sides, so the gap leads into the written ending.
- **T-09, "start a new story":** a **New story** button clears the editor and
  sketches; the previous story is kept in History.

## Assumptions
- Graded partial without notes: the causes above are guesses from the code.
- To regenerate a sentence you wrote, clear it first; TaleBrush only rewrites
  blanks and its own sentences.
- New story keeps the protagonist's name.

## Substitutions
Unchanged from v1: Claude Haiku through the LLM bridge in place of GPT-Neo
with soft prompts and the modified GeDi; surprise as an instruction rather than
temperature; candidates scored in one call instead of separate regenerations.
