Built by Claude Code (Claude Opus 5.5) from the paper.
All the interface features of Sections 3–4 work: sketching the protagonist's fortune, with drawing speed setting the band width and the number of regenerations; the generated story drawn back over the sketch; infilling; the eraser for unconstrained sentences; Generate Again; the surprise panel; and History with hover preview and roll back. The paper's trained models are replaced by a prompted LLM, so fortune reading and steering are only as good as the prompt.

(The group graded this build directly. The feature-check step was not run, so this build is v1.)

## Built
- Text editor with one bullet per sentence: Enter adds a bullet, and Backspace at the start of a bullet merges it into the one above. Each written sentence is a grey dot at its recognized fortune. Blank bullets leave gaps.
- "<name>'s fortune" field and **Generate Again** button above the canvas.
- Fortune canvas: pen strokes draw a green hatched band. Slow drawing gives a thin band (2 regenerations), fast drawing a wide one (1). Faint vertical lines mark sentence units.
- Lifting the pen generates a sentence for each slot under the stroke and plots it as a blue dot and line. A redrawn part regenerates only those slots.
- Infilling when story text follows the sketched gap (alternating from the previous and from the next sentence). Otherwise continuation.
- Eraser: erased slots are generated with no fortune target.
- Regeneration as in Section 5.2.2: a sentence more than 0.2 from the target is generated again, and the closest candidate is kept.
- "Surprise in a separate panel": a second canvas with a thin line that sets surprise per sentence.
- History dropdown: every generation is stored. While the menu is open, all arcs show faintly. Hover previews a story's text and arc, click rolls back to it, and ✎/✕ rename and delete.
- Editing a sentence re-reads its fortune and moves its dot.

## Assumptions
- Lifting the pen starts generation right away. Erasing and drawing surprise wait for Generate Again.
- Generate Again regenerates every sketched slot, including erased (unconstrained) ones.
- The editor starts with 8 bullets. Surprise is 0.3 (low) where none is drawn.
- Recognition gives the model up to 3 previous sentences as context, as in the paper.

## Substitutions
- GPT-Neo 2.7B with soft prompts (recognition and generation) and the modified GeDi on GPT2-medium are replaced by Claude Haiku, prompted through the workshop LLM bridge. This is labelled in the interface footer.
- Surprise was the softmax temperature in the paper. The bridge ignores temperature, so surprise is described in the prompt instead.
- On regeneration, the rejected sentences are listed in the prompt so that the model writes something different (a prompted model at fixed settings tends to repeat itself).
- Flask back end → Python standard-library server. React → plain JavaScript.
