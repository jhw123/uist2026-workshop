Built by Claude Code (Claude Opus 5.5) from the paper.
All interface features of Section 4 are in place and work end to end with the
stub. Generation and fortune recognition with a real language model are not
tested yet, because the `claude` CLI on this laptop was not signed in when v1
was finished.

## Built
- **Text editor** with one bullet per sentence. Enter adds a bullet, Backspace
  on an empty bullet deletes it, and generated sentences are marked blue.
  There is a Title field.
- **"<name>'s fortune"** field for the protagonist.
- **Canvas.** Each written sentence is a gray dot. Its height is the fortune
  recognized by the model, using up to three previous sentences and the
  protagonist. Dots are left to right in bullet order and joined by a line, and
  a blank bullet leaves a gap. Subtle vertical lines mark the sentence slots.
- **Sketching the fortune arc** in one stroke, shown as a green hatched band.
- **Sketching speed sets the band width.** Slow gives a thin band: tighter
  tolerance and up to 2 regenerations. Fast gives a wide band: looser, 1
  regeneration. The width changes gradually along the stroke.
- **Generate by sketching.** Lifting the pen generates one sentence per
  sketched slot, including infilling between written sentences. The result is
  recognized again and drawn as a blue line over the sketch.
- **Recognize-and-regenerate loop** (Section 5.2.2). A slot whose fortune
  misses its target by more than the band's tolerance is regenerated, and the
  closest candidate is kept.
- **Generate Again** with the same sketch.
- **Partial redraw.** Only the slots under the new stroke are regenerated.
- **Eraser** for "broken" lines. Erased slots get sentences with no fortune
  target.
- **Direct editing** of generated sentences. The edited sentence's dot moves,
  and later generations use it as context.
- **Surprise in a separate panel**: a second, aligned canvas with a thin line
  that sets surprise per sentence.
- **Multi-story management.** A History dropdown stores every generated story
  plus the initial one. All arcs are drawn faintly on the canvas. Hovering an
  entry previews its text and highlights its arc, clicking rolls back, and
  entries can be renamed or deleted.

## Assumptions
- 8 sentence slots at minimum, so there is room to sketch after a short
  opening (Figure 1 A2 shows blank bullets). Adding bullets adds slots.
- A slot counts as sketched when a third of its width is covered. A stroke
  regenerates a slot when it covers 40% of it or its centre.
- The band's half-width (0.05 to 0.25 on the 0–1 fortune scale) is the
  tolerance used for regeneration. The paper used a fixed 0.2 threshold with
  1–2 retries chosen by speed.
- Generate Again regenerates generated sentences in the sketched range, but
  keeps sentences the writer wrote or edited.
- The canvas shows faint "better/worse" labels. The paper's study version had
  no axis labels (Section 7.2).
- Sketching the surprise line does not generate by itself. Use Generate Again,
  or sketch fortune.

## Substitutions
- **Fortune recognition.** The paper uses GPT-Neo 2.7B with soft prompts trained
  on crowdsourced ROCStories fortune labels. Neither the prompts nor the data
  are available. Instead the model on the workshop LLM bridge (Claude Haiku) is
  prompted with the same inputs and a 0–1 scale.
- **Controlled generation.** The paper uses a modified GeDi (GPT2-medium) with
  continuous control codes steering GPT-Neo. Instead the bridge model is
  prompted with a numbered outline: a fortune target per slot, written context
  before and after each slot, and earlier versions to avoid for Generate Again.
  All slots are written in one call. This replaces the paper's separate
  continuation, infill-from-previous and infill-from-next prompts.
- **Surprise** is described in the prompt (predictable … wild twist) instead of
  setting the base LM's softmax temperature, which the bridge ignores.
- **Implementation.** Plain JavaScript and SVG instead of React, and the Python
  standard library instead of Flask, so nothing needs installing.
- `--stub` mode returns canned sentences and keyword fortune scores, with a
  banner saying so. It is only for trying the interface without a model.
