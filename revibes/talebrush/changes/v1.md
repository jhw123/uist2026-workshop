Built by Claude Code (Claude Opus 5.5) from the paper.
Writers name a protagonist, write or sketch, and TaleBrush generates sentences that
follow the sketched fortune arc. Every feature in the interface section works. The
paper's trained models are replaced by an LLM through the workshop bridge, so how
closely sentences follow small changes in the sketch depends on that model.

## Built
- Text editor with bullet-point sentences (Enter adds, deleting removes). Generated
  sentences are marked blue, the writer's gray, and blank bullets show as gaps.
- Protagonist name ("___'s fortune") and a Title field.
- Fortune canvas: one stroke sketches the arc. Sketching speed sets the envelope width
  (slow is tight, fast is loose), drawn as a hatched green envelope, with subtle
  vertical lines at each sentence.
- Fortune recognition of every sentence, using up to 3 previous sentences and the
  protagonist, shown as a line and dots on the sketch.
- Generation by sketching: continuation, and infilling that alternates "from previous"
  and "from next". A sentence is regenerated when the recognized fortune misses the
  target by more than 0.2, 1–2 more times depending on sketch tightness, and the
  closest one is kept.
- Redrawing part of the arc regenerates only that part. The eraser makes broken lines,
  which get unconstrained sentences. Generate Again keeps the same sketch.
- "Surprise in a separate panel": a second canvas with a thin line, from Low to High
  Surprise.
- Multi-story management: a History dropdown stores each generation. Stored arcs show
  at low opacity, hovering previews the text and highlights the arc, and clicking rolls
  back. Stories can be renamed and deleted.

## Assumptions
- Sentences the writer types or edits become theirs: kept as context, never
  regenerated.
- Stored arcs are drawn only while the History dropdown is open.
- A surprise sketch takes effect on the next generation; it does not generate on its own.
- Slow sketching (half-width under 0.1) allows two regenerations, otherwise one.
- New stories start with 8 bullets.

## Substitutions
- GPT-Neo 2.7B with soft prompts (recognition and generation) and GeDi-guided
  GPT2-medium are replaced by Claude Haiku through the LLM bridge. The paper's input
  layouts are kept as discrete prompts, and the target fortune is given as a number,
  in words, and as a direction of change. Labelled in the interface footer.
- Surprise is phrased in the prompt instead of setting softmax temperature (the bridge
  ignores temperature).
- Python standard-library server in place of Flask, and plain JavaScript in place of
  React (no installs needed).
