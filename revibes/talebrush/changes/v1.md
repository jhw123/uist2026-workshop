Built by Claude Code (Claude Opus 5.5) from the paper.
The group graded the first build directly (no separate debug or feature-check
round), so it is recorded here as version 1. Sketching the fortune arc,
generation that follows it, surprise, and History all work; the browser
interface was not tested by the agent, only the back end.

## Built
- Text editor with bullet points (one sentence each), title, and the
  "<name>'s fortune" protagonist field.
- Fortune recognition of every written sentence, shown as dots joined by a line
  on the canvas, with gaps for blank bullets (gray = writer, blue = generated).
- Line sketching on the canvas: x = sentence slot (subtle vertical lines), y =
  fortune. Sketching speed sets the envelope width (slow = thin = tighter).
- Generation on pen-up: continuation, infill from previous and infill from next,
  with regeneration when the recognised fortune is more than 0.2 off the sketch
  (1 or 2 extra tries depending on the width).
- Eraser: erased slots are generated without a fortune target.
- Generate Again; redrawing part of the sketch regenerates only that part.
- "Surprise in a separate panel." canvas.
- History dropdown: stored stories, faint arcs on the canvas, hover preview,
  click to roll back, rename and delete.

## Assumptions
- The editor starts with 10 empty bullets.
- A stroke regenerates every slot it covers.
- An edited generated sentence becomes the writer's (gray) and is context for
  later generations.
- Drawing on the surprise canvas does not start a generation by itself.
- Speed-to-width mapping: half-width 0.05–0.28; below 0.14 gives 2 extra tries.

## Substitutions
- GPT-Neo 2.7B with soft prompts (recognition) and modified GeDi on
  GPT2-medium (controlled generation) are replaced by prompting Claude Haiku
  through the workshop LLM bridge. Labelled at the bottom of the page.
- Surprise is an instruction to the model, not softmax temperature (the bridge
  ignores temperature).
- Regeneration asks for 2–3 candidates in one call and scores them in one call.
- React + Flask replaced by plain JavaScript and a standard-library Python server.
