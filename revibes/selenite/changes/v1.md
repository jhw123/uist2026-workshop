Built by Codex (GPT-6) from the paper.

Version 1 supports global grounding, annotated reading, and next-step guidance in
the Chrome extension and local excerpt reader. The Step 3 pass added end-of-article
guidance, combined criteria ranking, and inline criterion labels, and corrected
navigation, page reassignment, and skipped-criterion tracking. NLP algorithms use
the documented Codex bridge substitutions; arbitrary-site compatibility is limited.

## Built
- Topic recognition and manual topic management; common criteria with descriptions
  and diversity refinement with combined importance ranking; encountered options;
  pin/edit/reorder/add/delete; links to the topic's previously analyzed articles.
- Current-page coverage and mention counts, paragraph criterion labels, previous/
  next navigation, exact-quote sentiment highlights with inline criterion labels,
  overlapping/repeated phrase support, and option attribution.
- Two-second attention estimates, page-specific skipped criteria, cumulative
  progress, and two unseen-criterion search suggestions. An end-of-article summary
  automatically requests suggestions after complete analysis and reading to the
  end, with a checkbox to disable automatic requests.
- Local persistence, explicit page chunks or confirmed whole-article batches
  with stop control; changed criteria require reanalysis before gap suggestions.
- Step 2 Python cache-folder launch fix; visible errors without fabricated results.

## Assumptions
- Initial overview requests 15 criteria, then five additional diverse criteria.
- Paragraphs count as attended after two seconds visible on a focused active page.
- Navigation wraps. Manual criterion order overrides future model ranking.
- Progress appears in the sidebar and after the article's last paragraph.
- Whole-article batches require confirmation; automatic suggestions run once per
  complete analysis. These use the group's existing Codex plan.

## Substitutions
- Bridge-configured fast Codex model replaces GPT-4; no temperature control or
  ten-sample topic majority voting. Summary/topic and detail/subject stages are combined.
- Semantic model classification replaces BART-large-MNLI (no 0.96-score claim).
- Model topic matching replaces SentenceBERT clustering; model selection of two
  unseen criteria replaces the GPT-2/SentenceBERT graph algorithm.
- Dependency-free JavaScript/shadow DOM replaces React/TypeScript; Python standard
  library and browser-local persistence replace Firebase and authentication.
- Toolbar activation replaces automatic activation on every visited page.
