# Revibes

The agent creates one folder per revibe here, `revibes/<paper>/`:

    app/             the rebuilt system, with its README.md and DEVELOPER.md
    changes/         v1.md, v2.md, ...: what each version built or changed
    grades/          v1.md, v2.md, ...: the group's grades, pasted from the hackathon page
    remixes.md       remixes, after the revibe
